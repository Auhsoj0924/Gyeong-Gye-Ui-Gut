# 경계의 굿 — Prototype 5 (26.10.12)

한국 설화풍 무당 4인 파티가 윷 기반 3승 경합으로 끝없이 몰려오는 감정의 망령과 싸우는 바닐라 웹 턴제 RPG 프로토타입입니다.
SPEC은 `openspec/changes/build-korean-shaman-infinite-rpg/`(작업 사본: `Shamanism/`)을 따릅니다. Prototype 4(마탑)와는 파일·저장 데이터를 공유하지 않습니다.

## 실행

ES 모듈을 쓰므로 `index.html`을 파일로 직접 열지 말고 로컬 웹 서버로 띄웁니다. 이 폴더에서:

```bash
python -m http.server 8125
```

그 다음 브라우저에서 `http://localhost:8125`를 엽니다. (`npm start`도 같은 명령입니다.)

### 주소 옵션

| 옵션 | 설명 |
|---|---|
| `?seed=123` | 난수 시드 고정 (같은 시드 = 같은 스킬 공개·윷·적 구성) |
| `?dev=1` | 개발 패널: 신명 100 충전, 모든 스킬 공개, 다음 보스 스테이지로 이동, 적 HP 1, 파티 HP 1 |

브라우저 콘솔에서 `__shaman.battle`로 현재 전투 상태를 볼 수 있습니다.

## 테스트

```bash
node tests/run-tests.js
```

외부 의존성 없이 Node(ES 모듈)로 순수 규칙과 전투 상태 머신을 검증합니다(tasks.md 1.x–6.x, 8.x 자동 플레이 포함).

## 무한 모드 목표

1스테이지부터 시작해 전멸할 때까지 최대한 깊이 내려갑니다. 5의 배수 스테이지는 보스 스테이지이고(분노 → 불안 → 집착 → 절망 순환), 최고 도달 스테이지는 브라우저 `localStorage`(`shaman-p5-best`)에 저장됩니다. 저장소가 막혀 있으면 세션 기록만 표시하고 게임은 계속됩니다.

## 조작

1. 무당 카드에서 공개된 스킬을 누르고, 전장의 적 또는 카드 안 **대상 선택** 목록에서 적을 고릅니다.
2. 같은 적을 여럿이 고르면 **마지막 지정자만 경합 담당**, 앞선 지정자는 **일방 공격**으로 표시됩니다.
3. 아무도 고르지 않은 적은 오른쪽 패널에 **비경합 위협**(예상 피해·디버프·대상 확률)으로 표시됩니다.
4. 생존 무당 전원의 명령을 정하면 **턴 확정**. 해결 연출은 `연출 ×1/×2/×4`로 빠르게 하거나 **연출 건너뛰기**로 생략할 수 있습니다.
5. 신명 100이 되면 프로필을 **0.8초 이상 길게 누르거나** 카드의 **강신합일** 버튼(클릭·키보드 대체 입력)으로 스킬 한 칸을 강신합일 스킬로 교체합니다.
6. `Esc`로 대상 선택이나 창을 닫습니다. 소리는 첫 클릭/키 입력 때 켜지며 `소리 켬/끔`으로 음소거합니다.

```text

src/data.js      모든 콘텐츠·튜닝 수치 (속성, 상성 16칸, 상태이상, 파티, 스킬, 적, 보스, TUNING)

src/battle.js    전투 상태 머신 (STAGE_START → … → APPLY_END_TURN_UPDATES), 이벤트 발행, 기록 저장
```

## 튜닝 테이블

수치는 모두 `src/data.js`에 있습니다. 규칙 코드는 수치를 하드코딩하지 않습니다.

| 항목 | 값 | 위치 |
|---|---|---|
| 스킬 공개 확률 | 1+2 65% · 1+3 25% · 2+3 10% | `TUNING.pairWeights` |
| 강신합일 대기 시 다른 칸 | 1스 60% · 2스 30% · 3스 10% | `TUNING.singleSlotWeights` |
| 경합값 | (경합위력 + 윷값) × 경합 상성 − 흐트러짐 | `rules.calculateClashValue` |
| 상성 배율 | 데미지 2.0/1.5/1.0/0.5 · 경합 1.20/1.10/1.00/0.90 | `MATCHUP_LEVELS` |
| 비경합 공격 | 일반 ×1.25 · 보스 ×1.50 | `TUNING.unopposedMultiplier` |
| 어그로 | 전열 50 · 중열 35 · 후열 15, 액막이 충전 시 한도윤 +20 | `POSITIONS`, `TUNING.tankAggroBonus` |
| 정신력 | 기본 50 · 경합 승리 +3 · 패배 −8 · 비경합 피격 −10 | `TUNING.mental` |
| 신명 | 경합 승리 +20 · 패배 +8 · 일방 공격 적중 +5 · 살풀이 공명 +8/+10/+15 | `TUNING.shinmyeong`, 스킬 `resonance` |
| 보스 전용 행동 | 3턴마다 | `TUNING.bossActionEvery` |
| 스테이지 성장 | 일반 HP +18%/구간 +3%/단계, 데미지 +12%/+2% · 보스 HP 1.5+0.25, 데미지 1.2+0.15 | `TUNING.scaling` |
| 회복 | 생존자 HP 최대·정신력 100, 보스 정화 시 사망자 HP 30%·정신력 50 | `TUNING.recovery` |

## SPEC에 없던 부분의 구현 기본값

- 경합 승리 정신력 +3, 비경합 피격 정신력 −10, 경합 승리 신명 +20 (초기 tasks 값 유지).
- 보스 전용 행동은 스테이지 기준 3·6·9…턴에 발동하고, 그 턴 시작 시 적 카드에 예고합니다. 기본 공격 턴에는 디버프가 없고, 전용 행동 데미지는 보스 기본 데미지입니다.
- 끝없는 곡의 HP 5% 회복은 보스 자신의 최대 HP 기준입니다.
- 적 쪽 경합값에는 상성 배율을 적용하지 않습니다(×1.0). 적 정신력은 금오 현신(−5) 같은 효과로만 바뀝니다.
- 일반 적 구성은 4종 중 무작위(중복 허용), 보스 보조 적도 같은 방식입니다.
- 봉인·액막이 충전은 더해지며 최대 2입니다. 금오 여명강림의 "다음 피해 ×1.25"는 `취약`(1회 소모) 상태입니다.
- 흐트러짐 −1은 상성 배율을 곱한 뒤 뺍니다. 다음 경합 1회 동안(모든 라운드) 적용되고 소모됩니다.
- 바리의 길 열기의 디버프 제거는 아군마다 1개씩입니다. "HP가 가장 낮은 아군"은 HP 비율 기준입니다.
- 윤초희가 경합에서 이기면 경합 승리 신명(+20)과 살풀이 공명을 둘 다 받습니다(직업 효과·강신합일 회복은 공명 없음).
- 적 디버프는 비경합 공격에서 반드시 걸리고, 경합에서 이긴 적의 공격에는 보스 전용 행동의 효과만 걸립니다.
- 정신 동요·속박·치유 감소는 걸린 턴이 아니라 다음 턴부터 지속 턴이 줄어듭니다(원혼 파열·출혈은 걸린 턴 종료 시부터 피해).
- 액막이 대신 받기는 적의 공격 피해에만 적용되고 지속 피해(원혼 파열·출혈)에는 적용되지 않습니다. 대신 받은 공격의 디버프도 한도윤이 받습니다.
- 강신합일 스킬을 일방 공격(같은 적의 앞선 지정)으로 써도 적중하며 강화 효과와 신명 소모가 적용됩니다.

장비, 레벨, 성장, 가챠, 파티 편성, 스킬 트리, 영구 강화, 계정, 온라인 기능, 서버 저장, 진행 중인 런 저장(새로고침 시 새 런), 성우 음성.
